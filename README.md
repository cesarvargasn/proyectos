# Proyectos

Código de mis proyectos personales y académicos, cada uno en su carpeta con su propio README.
La ficha de cada uno vive en [cesarvargasn.com/proyectos](https://cesarvargasn.com/proyectos).

| Carpeta | Qué es | Herramientas |
|---|---|---|
| [`analisis-de-datos/`](analisis-de-datos) | Seis estudios econométricos con datos de hogares colombianos | Stata |
| [`montecarlo-finanzas/`](montecarlo-finanzas) | Simulación Monte Carlo del VPN de un modelo financiero en Excel, estilo Crystal Ball | Python, Excel |
| [`whatsapp-analisis/`](whatsapp-analisis) | Métricas de un chat exportado de WhatsApp: participación, quién inicia, palabras | Python, pandas |
| [`ocr-app/`](ocr-app) | App de escritorio que saca texto de imágenes y PDF a .txt o .docx | Python, Tesseract |
| [`gastos/`](gastos) | App Android que registra gastos leyendo los SMS del banco, más un visualizador local | Kotlin, Python, Supabase |
| [`la-noche/`](la-noche) | Plataforma de juegos de fiesta en vivo: el host corre la sesión y los invitados juegan desde el celular (sin las cartas) | React, TypeScript, Supabase |
| [`afinidad/`](afinidad) | App de afinidad para fiestas: cuestionario, similitud coseno y grupos en rondas embudo (sin las preguntas) | React, TypeScript, Supabase |
| [`otros/`](otros) | Experimentos chicos: visor de bolsa y un scraper con interfaz | Python |

Ningún proyecto incluye datos originales ni personales.
